# OptiPlan Pro - Project Management & Resource Engine

**OptiPlan Pro** is a modern, full-featured project management application designed for agile teams, project managers, and tech leads. It combines real-time WBS file parsing, interactive task Kanban boards, Gantt chart timeline visualizers, team resource cost management, and automated schedule optimization into a unified interface.

---

## 🌟 Key Features

### 📋 1. Interactive Task Board & Kanban Workflow
- **Four Standard Execution Columns**: *To Do*, *In Progress*, *Review*, and *Done*.
- **Explicit Save Controls**: Modal task edits remain isolated in temporary state until explicitly selecting **Save Changes**, ensuring no unintended background updates occur.
- **Department & Priority Tagging**: Visual indicators for engineering, design, management, and product teams.
- **Task Search & Filtering**: Instant global keyword search across titles, task codes, assignees, and status tags.

### 📁 2. Intelligent Project File Import & Mapping Engine
- **Multi-Format Support**: Parse project files in `.json`, `.csv`, `.txt`, `.xml`, and `.wbs` formats.
- **Automated Property Mapping**: Automatically extracts and maps core project attributes (*Project Name*, *Client Sponsor*, *Budget*, *Start/End Dates*) and WBS tasks.
- **Smart Feedback Reports**:
  - **Unmapped Fields Warning**: Highlights custom or non-standard file attributes that could not be mapped.
  - **Missing Task Fields Report**: Identifies tasks with missing required properties (e.g., Title, Status, Assignee, Due Date) before importing.

### 📊 3. Interactive Gantt Chart Timeline
- **Visual Schedule View**: Bar-chart timeline visualizing task progress, dependencies, and completion percentages.
- **Status & Department Colors**: Color-coded progress bars for quick visual status assessment across team departments.

### 👥 4. Resource Allocation & Financial Management
- **Resource Directory**: Manage team members, departmental assignments, and job roles.
- **Live Cost Calculation**: Dynamically calculates total monthly personnel costs and budget utilization.
- **Departmental Cost Distribution**: Visual bar breakdown of resource spend by department (*Engineering*, *Design*, *Management*, etc.).

### ⚡ 5. Real-Time Schedule & Resource Engine (Auto-Optimize)
- **Multi-Stage Optimization**: Simulates real-time resource leveling, critical path analysis, and risk buffer smoothing.
- **Metric Insights**: Generates schedule efficiency ratings and cost reduction projections.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or later) installed on your system.

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/joonhoe-ong/Project-Management-App.git
   cd Project-Management-App
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

### Building for Production

To create an optimized production build:
```bash
npm run build
```

## 📖 Usage Guide

1. **Creating or Importing a Project**:
   - Click **+ New Project** in the header.
   - Enter core details or drag and drop a project file (`.csv`, `.json`, etc.) into the Work Breakdown Structure dropzone.
   - Review any unmapped fields or missing task field warnings generated by the mapping engine.
2. **Managing Tasks**:
   - Navigate to the **Task Board** tab.
   - Click on any task card to open the **Task Detail** modal.
   - Edit the task details and click **Save Changes** to commit updates.
3. **Tracking Timeline**:
   - Switch to the **Gantt Chart** tab to inspect task schedules and progress.
4. **Managing Resources**:
   - Select **Resource Management** to view team members, add resources, and adjust monthly rates.
5. **Auto-Optimizing Schedules**:
   - Click **Auto-Optimize** in the top navigation bar to trigger the automated schedule leveling simulation.
